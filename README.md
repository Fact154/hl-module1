# Система управления музеем

Проект представляет собой микросервисную архитектуру для управления музейными данными и статистикой.

## Архитектура

Проект состоит из следующих компонентов:
- Основное приложение (museum-app)
- Сервис статистики (statistics-service)
- База данных PostgreSQL
- Административный интерфейс pgAdmin

## Взаимодействие между сервисами

### Основное приложение (museum-app)
Основное приложение предоставляет REST API для управления:
- Экспонатами (exhibits)
- Посетителями (visitors)
- Экскурсиями (tours)
- Метриками производительности (metrics)

### Сервис статистики (statistics-service)
Сервис статистики взаимодействует с основным приложением через HTTP API для:
- Получения данных об экскурсиях
- Анализа и агрегации статистики
- Предоставления рейтинга экспонатов

## API Endpoints

### Основное приложение (http://localhost:8080)

#### Экспонаты
- `POST /exhibits` - создание нового экспоната
- `GET /exhibits/{id}` - получение информации об экспонате
- `GET /exhibits` - получение списка всех экспонатов
- `DELETE /exhibits/{id}` - удаление экспоната

#### Посетители
- `POST /visitors` - регистрация нового посетителя
- `GET /visitors/{id}` - получение информации о посетителе
- `GET /visitors` - получение списка всех посетителей
- `DELETE /visitors/{id}` - удаление посетителя

#### Экскурсии
- `POST /tours` - создание новой экскурсии
- `GET /tours/{id}` - получение информации об экскурсии
- `GET /tours` - получение списка всех экскурсий
- `DELETE /tours/{id}` - удаление экскурсии

#### Метрики
- `GET /metrics` - получение метрик производительности

### Сервис статистики (http://localhost:8081)

#### Статистика
- `GET /api/statistics/exhibit-rating?year={year}&month={month}` - получение рейтинга экспонатов за указанный период

#### Метрики
- `GET /metrics` - получение метрик производительности сервиса статистики

## Запуск проекта

1. Скопируйте файл `.env` и настройте переменные окружения
2. Запустите проект с помощью Docker Compose:
```bash
docker-compose up -d
```

После запуска сервисы будут доступны по следующим адресам:
- Основное приложение: http://localhost:8080
- Сервис статистики: http://localhost:8081
- pgAdmin: http://localhost:5050

## Тестирование производительности

Для тестирования производительности используются скрипты K6:
- `simple_k6.js` - базовый тест
- `simple_k6_v2.js` - улучшенная версия
- `simple_k6_v3.js` - последняя версия

## Генерация тестовых данных

Для генерации тестовых данных используются Python-скрипты:
- `generate_data_api.py` - генерация через API
- `generate_data2.py` - альтернативный метод генерации

## Очистка данных

Для очистки данных используются скрипты:
- `clear_data.py`
- `clear_data2.py`

## Мониторинг и анализ

- Результаты тестов сохраняются в `results.csv`
- Для визуализации результатов используется `plot.py`
